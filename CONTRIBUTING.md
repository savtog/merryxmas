# Contributing

Issues and pull requests are welcome
on [Codeberg](https://codeberg.org/savtog/merryxmas).

If you would like a new feature to be added, please create an issue for it
first so that it can be discussed before you start working on it.

New trees and deer are welcome too: see "Drawing your own tree or deer" in
the [README](https://codeberg.org/savtog/merryxmas#drawing-your-own-tree-or-deer).

## Note

The [GitLab](https://gitlab.com/savtog/merryxmas) and
[GitHub](https://github.com/savtog/merryxmas) versions of this project are
push mirrors. Any issues or pull requests submitted there will be closed.
